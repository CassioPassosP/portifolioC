# Portfólio | Cassio Passos

Portfólio pessoal desenvolvido para apresentar minha trajetória, minhas habilidades e alguns projetos desenvolvidos durante minha formação em tecnologia.

## Sobre o projeto

Este projeto é uma página web estática, responsiva e acessível diretamente pelo navegador. O portfólio reúne:

- Apresentação pessoal e profissional;
- Tecnologias e ferramentas utilizadas;
- Projetos desenvolvidos;
- Links para redes profissionais e contato;

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Git e GitHub

## Como executar o projeto

Como este é um projeto estático, não é necessário instalar dependências ou configurar um servidor backend.

### Opção 1: abrir diretamente no navegador

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

### Opção 2: usar o VS Code

1. Abra a pasta do projeto no VS Code.
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html`.
4. Selecione **Open with Live Server**.

## Publicação no GitHub Pages

Para publicar o projeto gratuitamente pelo GitHub Pages:

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto para a branch `main`.
3. Acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve as configurações e aguarde a geração do endereço público.
